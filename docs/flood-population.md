# 浸水想定区域内の人口推計

プレゼン資料(要件定義書 §9)の課題設定で使う数値をまとめる。
算出は `scripts/flood-population.py` で再現でき、出力は `docs/data/flood-population.json` に入る。
同じスクリプトが、人口レイヤー(F-14)のバンドルデータ `src/constants/population-mesh.json` も生成する。

対象は**想定最大規模**の洪水浸水想定区域である。
水防法にもとづき河川管理者が指定した区域のうち、想定しうる最大規模の降雨を前提としたもので、アプリのハザードマップ表示(F-07)と同じ前提を指す。

## 主要な数値

2020年国勢調査を基準年とした値を主に使う。

| 項目                             | 人数     | 市人口に占める割合 |
| -------------------------------- | -------- | ------------------ |
| 直方市の人口                     | 56,427人 | 100%               |
| 浸水想定区域内                   | 22,847人 | 40.5%              |
| 浸水深 0.5m 以上の区域内         | 21,708人 | 38.5%              |
| 浸水深 3.0m 以上の区域内         | 14,977人 | 26.5%              |
| 家屋倒壊等氾濫想定区域(氾濫流)内 | 2,232人  | 4.0%               |

浸水想定区域は市域面積の 23.8% にすぎない。
面積で4分の1に満たない範囲に、市民の4割が住んでいる。
市街地が遠賀川沿いの低地に形成されてきた結果であり、人口密度の高い場所ほど浸水想定が深い。

浸水深ランク別の内訳は次のとおりである。
ランクの区分と説明は国土数値情報の浸水深ランクコードに従う。

| 浸水深                           | 人数     | 市人口に占める割合 | 市域面積に占める割合 |
| -------------------------------- | -------- | ------------------ | -------------------- |
| 0〜0.5m未満(床下程度の浸水)      | 1,139人  | 2.0%               | 1.5%                 |
| 0.5〜3.0m未満(床上から1階が浸水) | 6,731人  | 11.9%              | 8.5%                 |
| 3.0〜5.0m未満(2階部分が浸水)     | 13,560人 | 24.0%              | 11.7%                |
| 5.0〜10.0m未満(2階部分が水没)    | 1,417人  | 2.5%               | 2.1%                 |

最も人数が多いのは 3.0〜5.0m の区域で、13,560人が住む。
2階へ上がる垂直避難では水面より下になる深さである。

## 高齢者と将来推計

メッシュ人口データは2025年以降について年齢階級別の推計を持つ。

| 年     | 市人口   | 浸水想定区域内 | 割合  | うち65歳以上 | うち75歳以上 |
| ------ | -------- | -------------- | ----- | ------------ | ------------ |
| 2025年 | 54,897人 | 22,321人       | 40.7% | 7,571人      | 4,520人      |
| 2050年 | 45,396人 | 18,605人       | 41.0% | 6,869人      | 4,175人      |

2025年時点で、警戒レベル3(高齢者等避難)の対象となる65歳以上のうち 7,571人が浸水想定区域内にいる。
市全体の65歳以上 18,878人に対して 40.1% にあたる。

2050年には市人口が 45,396人まで減る一方、浸水想定区域内の割合は 41.0% と下がらない。
人口が減ってもリスクにさらされる人の割合は変わらない、という見通しになる。

## 算出方法

### 使ったデータ

- **500mメッシュ別将来推計人口(R6国政局推計)**:2020年国勢調査を基準年とし、2070年までを5年ごとに推計した500mメッシュ単位の人口。国土交通省 国土政策局
- **洪水浸水想定区域データ(河川単位)2025年度版**:河川管理者が指定した洪水浸水想定区域を浸水深ランク別のポリゴンにしたもの。福岡県管理河川は都道府県別、遠賀川など国管理河川は九州地方整備局別のファイルに分かれる
- **行政区域データ(2025年1月1日)**:市域の切り出しに使う
- **令和2年国勢調査 小地域(町丁・字等)境界(e-Stat)**:人口レイヤーの各メッシュに代表の地域名(「大字感田」等)を付けるのに使う。本ドキュメントの集計値には関与しない

### 按分の考え方

メッシュ内では人口が一様に分布すると仮定し、浸水想定区域との重なり面積の比で人数を按分した。
浸水深ランクは河川ごとのポリゴンが重なるため、深いランクを優先して排他的な面に組み直してから集計している。

メッシュ人口データは、1つのメッシュを1つの市区町村コードにしか割り当てない。
市区町村コードで絞ると、市境をまたぐメッシュの人口が隣接自治体へ丸ごと寄り、直方市の人口を 2,000人以上取りこぼす。
そのため市域でクリップした面積比による按分に切り替えた。

### 検証

この方法で得た市全体の人口は 56,427人となり、2020年国勢調査の直方市人口 56,212人との差は +0.4% に収まる。
按分が市の実人口とほぼ一致することを、数値を使う前提としている。

### 留意点

- メッシュ内の人口一様分布は仮定である。実際には住宅地に偏るため、低地に市街地が集中する直方市では浸水域内の人数をやや**過小に**見積もる可能性がある
- 小地域(町丁字)単位ではなく500mメッシュ単位のため、地区ごとの数値としては使えない
- 2020年は総人口のみで、年齢階級別の値は2025年以降にしかない
- 家屋倒壊等氾濫想定区域は遠賀川のぶんだけが整備されている。支川ぶんは含まない

## 出典表記

いずれも国土交通省 国土数値情報のオープンデータ(CC BY 4.0)である。
資料に載せるときは加工した事実を明示する。

> 国土数値情報(500mメッシュ別将来推計人口データ、洪水浸水想定区域データ、行政区域データ)(国土交通省)を加工して作成

国勢調査人口との照合には、総務省統計局「令和2年国勢調査」の直方市人口を使った。

## 再現手順

```
pip3 install shapely pyshp
python3 scripts/flood-population.py
```

初回は国土数値情報から約200MBを取得して `.cache/flood-population/` に展開する。
2回目以降はキャッシュを使うため、集計だけで30秒ほどで終わる。
