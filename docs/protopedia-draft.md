## プロトタイプ名

直方ベース

## 概要(サマリー欄)

遠賀川流域の直方市では、市域の 24% にあたる洪水浸水想定区域に市民の約4割・2.3万人が住んでいます。
複数のサイトに分かれている防災情報をスマホの地図1枚に集約し、AR でその場の想定浸水深を「体感」できるようにした市民向けアプリです。

## ストーリー(本文・Markdown)

第15回 e-ZUKA スマートアプリコンテスト2026 応募作品(分野: 災害)。

### 市民の4割が浸水想定区域に住む町

直方市は、遠賀川に彦山川と犬鳴川が合流する「川のまち」です。
国のオープンデータ(500m メッシュ推計人口と洪水浸水想定区域)を重ねて集計すると、市域面積の 24% にすぎない浸水想定区域に、市民の 40%(約2.3万人)が住んでいます。
市街地が川沿いの低地に発達してきた歴史の裏返しです。
さらにこの 2.3万人のうち約1.5万人は、2階に上がっても水面より下になる「浸水深 3m 以上」の区域に住んでいます。

この数字が本作の出発点です。

### 課題: 情報が分かれていて、スマホで見づらい

いざという時、直方市民が見るべき情報は複数の場所に分かれています。

- 避難所の開設状況や水位、被害報告は、市の「災害時情報共有プラットフォーム」(ArcGIS ダッシュボード)
- 浸水想定や土砂災害警戒区域は、Web 版ハザードマップ
- 遠賀川本川の水位や氾濫情報は、国の「川の防災情報」
- 避難情報のお知らせは、市の Web サイトや SNS
- 車中泊避難所の場所にいたっては、市の公式 LINE の配信でしか分からない

どれも情報自体は公開されているのに、置き場所が分かれ、画面は PC 前提でスマホでは操作しづらい。
「探せば見つかる」は、切迫した場面では「見つからない」と同じです。

そこで、公開データを1つの地図アプリに集約することにしました。

### つくったもの: 1枚の地図に、市の「いま」を集める

ホームの地図に、次のレイヤーを重ねて表示します。

- **避難所(50箇所)**: 開設状況と混雑度で色分け。一覧は開設中が上、自宅を設定すれば近い順
- **車中泊避難所(9箇所)**: LINE 配信でしか案内されていなかった場所を、地図でいつでも確認できるようにした
- **水位センサー20地点+転倒ゲート**: 警戒水位との比率で色分けし、数分おきの観測値を表示
- **被害報告・交通規制**: 市が公開したものだけを表示
- **ハザードマップ4種**: 洪水浸水想定、土石流、急傾斜地、家屋倒壊等氾濫想定区域を同時に重ねられる
- **人口メッシュ**: 500m ごとの推計人口を濃淡表示。タップすると「大字頓野 付近 約1,700人(65歳以上 約610人)」のように出る
- **川の防災情報へのリンク**: 遠賀川本川の詳しい水位や氾濫情報は、国の公式サイトへワンタップでつなぐ(数値の転載ではなく公式へ誘導)

「どこが危ないか(ハザード)」と「そこに何人住んでいるか(人口)」と「いまどうなっているか(水位・避難所)」を、1枚の地図で行き来できます。

### AR 浸水体験: 数字の「3m」を、目の前の水面に変える

ハザードマップの色分けを見ても、「3m 沈む」という危険は実感しづらいものです。
そこで ARKit の平面検出で床を認識し、カメラ映像の中に想定浸水深の水面を描画しました。
水面高さはスライダーで 0.5〜5m まで動かせて、地図のハザード表示から「この深さを体感する」ボタンで AR へつながります。
自宅の前で「2階の床まで水が来る」を見ることが、避難行動を考えるきっかけになると考えています。

### 全員に届けるための3つの工夫

**やさしい日本語モード。**
直方市の外国人住民は約1,030人(総人口の約1.9%)で、増加が続いています。
国籍が多国籍に分散しているため、特定言語への翻訳ではなく、日本語1言語で全国籍をカバーする「やさしい日本語」を選びました。
国が示す災害時コミュニケーションの方針に沿ったアプローチです。

**デモモード。**
平常時は水位も避難所も「異常なし」で、アプリの真価が見えません。
2023年7月豪雨を参考にした大雨災害シナリオを、通信なしで再現できるモードを用意しました。
災害時の姿をいつでも体験でき、通信が不安定な会場でもデモできます。

**じぶん設定。**
自宅の場所をピンで設定すると、避難所一覧が近い順になり、最寄り避難所がホームに出ます。
位置情報はアカウント登録なしで端末内にのみ保存し、外部には送信しません。

### 個人情報を「持たない」設計

本作にはサーバがありません。
アプリが公開 API を直接読み、取得するフィールドはホワイトリストで管理して、必要な項目以外(個人情報を含む項目)を最初から取得しません。
じぶん設定も端末内で完結します。
防災アプリは信頼が前提のため、「個人情報を守る」ではなく「そもそも持たない」を設計原則にしました。

### 技術構成

- React Native + Expo(dev client)、TypeScript
- AR: ViroReact + ARKit(平面検出、水面はプログラム生成テクスチャ)
- 地図: react-native-maps(Apple Maps)+ UrlTile。有料の地図 API キーは不要
- データ層: リポジトリパターンで、ライブ API とデモ用データを差し替え
- 人口・地域名: 国土数値情報と e-Stat の国勢調査境界をビルド時に加工して同梱(オフラインでも動作)

サーバ費用も API キーもゼロのため、プロトタイプのまま実運用に進められる構成です。

### 本作のオリジナリティ

- **課題の定量化から自作**: 「市民の4割が浸水想定区域に住む」は、国の公開データ(メッシュ人口と浸水想定区域)を自前で重ねて算出した数字です。市全体の合計が国勢調査と 0.4% 差で一致することを確認しています
- **「知る」から「体感する」へ**: ハザードマップの色分けを、AR の実寸の水面に変換します
- **危険と人の重ね合わせ**: 「どこが危ないか」に「そこに何人住んでいるか」を重ねる人口レイヤー
- **翻訳ではなく「やさしい日本語」**: 多国籍化する外国人住民への言語設計
- **個人情報を「そもそも持たない」**: サーバレス・運用費 0 円。プロトタイプですが、そのまま実運用に進められる構成です

### 稼働環境・使用技術・知的財産権

- **稼働環境**: iPhone(ARKit 対応機)。開発ビルドを実機にインストールして動作します
- **使用言語・技術**: TypeScript、React Native + Expo、ViroReact + ARKit、react-native-maps、Python(データ加工)
- **知的財産権**: ソースコードは MIT ライセンスで GitHub に公開しています。使用データはすべて出典を明記した公開データ、AR の水面テクスチャなどの素材はプログラム生成で、第三者の知的財産権に抵触する要素はありません

### これから: 実現したい地域

本作を通じて実現したいのは、市民の4割が持つ浸水リスクが「自分ごと」として知られている地域です。
リスクを知っている人が増えることが、被害を減らす最初の一歩だと考えています。

防災を入り口に、ごみ収集日や子育て情報も入る「市民生活ポータル」への発展を考えています。
使っているのは全国共通の公開データと市の公開 API のため、遠賀川流域の他の自治体にも同じ構成で横展開できます。

出典: 直方市 災害時情報共有プラットフォーム(公開用)、ハザードマップポータルサイト(国土交通省)、国土数値情報(国土交通省)および国勢調査 小地域境界データ(e-Stat)を加工して作成。
本アプリは直方市の非公式アプリです。避難の判断は市の公式情報に従ってください。
