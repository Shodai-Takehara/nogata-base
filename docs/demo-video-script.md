# デモ動画シナリオ(ProtoPedia 提出用・3分以内)

全体 2分48秒の設計。ナレーションは約680字で、落ち着いた速さで読める分量にしている。

## 事前準備

1. 自宅ピンを消すか、撮影用に市役所などへ動かす(公開動画から自宅が特定されないように)
2. 「設定 → コントロールセンター」に画面収録を追加。収録時はマイクをオフ(ナレーションは後入れ)
3. 通知を切る(おやすみモード)
4. シーン3〜6は通信ありで収録する(水位の取得時刻が「数分前」であることが実データの証明になる)
5. AR は明るい場所で、床がはっきり見える場所。屋外なら表札・ナンバーの映り込みに注意
6. 「川の防災情報」は収録前に一度開いておく(初回読み込みの待ち時間を収録に入れないため)
