## 1. 結論

B1 は実装できる。
J-SHIS の API は認証なしで直方市域の 250m メッシュを返し、市内の7地点を引いたところ、今後30年に震度6弱以上の揺れに見舞われる確率は 0.6% から 9.5% まで16倍の開きがあった。
この差は表層地盤(山地か、谷底低地か、自然堤防か)で説明でき、「同じ市内でも自分の場所で違う」という本アプリの主張にそのまま乗る。

B2 は治水地形分類図だけを採る。
遠賀川の氾濫平野は整備済みで、直方市域のタイルは北東の山地側を除いて存在する。
明治期の低湿地は直方市の南半分が未整備(タイルが 404)なので見送る。
空白を「安全」と読まれる恐れがあり、千葉豪雨の教訓(色が付いていない場所で浸水した)と逆の効果になる。

## 2. B1 地震ハザード(J-SHIS)

### 2.1 使うデータと確認した事実

**地震ハザード情報提供 API**[^jshis-api]。
250m メッシュごとに、30年以内に震度5弱以上、5強以上、6弱以上、6強以上となる確率と、超過確率3%および6%に対応する計測震度を返す。
経度緯度で引け、`epsg=4326` を指定すると WGS84 で返る。
認証はない。

```
https://www.j-shis.bosai.go.jp/map/api/pshm/Y2024/AVR/TTL_MTTL/meshinfo.geojson?position=130.73,33.74&epsg=4326
```

年版は `Y2024` が最新で、`Y2025` は 400 を返す(2026-09-12 確認)。
`Y2024` は「2024年基準の地震動予測地図(NIED 作成版)」で、評価基準日は 2024-01-01、公開は 2024-07-19 である[^jshis-2024]。
地震本部が公式に公表した「全国地震動予測地図」の最新は 2020年版なので、出典表記では NIED 作成版であることを書く。

**表層地盤情報提供 API**[^jshis-sstrct]。
同じ 250m メッシュの微地形区分(名称つき)、表層30mの平均S波速度、工学的基盤から地表までの最大速度増幅率を返す。

```
https://www.j-shis.bosai.go.jp/map/api/sstrct/V4/meshinfo.geojson?position=130.73,33.74&epsg=4326
```

**地震活動モデル情報提供 API**[^jshis-fltinfo]。
断層コードを指定すると断層モデルの矩形を返す。
福智山断層帯のコードは `F012101` で、主要活断層帯ベクトルタイル(`major_fault`)に含まれる断層名から特定した。
返る矩形は上端の深さ 3.0km、走向 165°、傾斜 75°、長さ 32km、幅 12km で、上端の2点は (130.726, 33.936) と (130.816, 33.657) である。
地表トレースではなく断層モデルの上端なので、線を引くときはその旨を凡例に書く。

### 2.3 凡例と読み方

地震本部の確率論的地震動予測地図は、30年以内に震度6弱以上となる確率を 0.1% 未満、0.1〜3%、3〜6%、6〜26%、26% 以上の5段階で塗り分ける[^jishin-legend]。
直方市中心の 9.5% は上から2番目の「6〜26%」に入る。
同じ解説は、この確率が相対的な指標で「安全度ではなく危険度を示す」こと、確率が低くても地震を身近な危険として捉える姿勢が要ることを注意書きにしている。
アプリでも同じ注意書きを凡例に添える。

### 2.4 利用規約

J-SHIS 利用規約[^jshis-terms]は次のように定めている。

- 転載や引用では出典が J-SHIS であることを明示する。地震動予測地図データを使うときもその旨を明記する
- データは編集や加工をして成果物を自由に頒布、譲渡、貸与できる。ただし「そのまま複製してそのまま頒布、譲渡すること」は禁じられている
- 成果物を販売する場合は申請が要ることがある(事前に問い合わせ)
- 利用は利用者の判断と責任で行い、防災科研は責任を負わない

API の呼び出し上限は規約に書かれていないが、仕様上は 403(上限超過)が定義されている[^jshis-api]。
アプリから直接呼ばず、ビルド時に市域ぶんを取り出して静的に持てば、この上限と NF-04(オフライン耐性)の両方を満たす。
市域を切り出して塗り分ける加工は「編集・加工」にあたり、そのままの複製ではない。

### 2.5 実装の形

人口レイヤー(F-14)と同じ方式にする。

1. ビルド時のスクリプトで、市域を覆う 250m メッシュ(面積約 62km² なので約1,000枚)を2つの API から取り出し、静的 JSON にする。1メッシュあたり確率4値、計測震度、増幅率、微地形区分コードを持たせて 100KB 前後になる見込み。API を約1,000回叩くことになるので、上限に当たるならダウンロードページの1次メッシュ(5030)単位の CSV に切り替える[^jshis-download]
2. 描画は人口レイヤーと同じ `Polygon` で行う。人口は 500m メッシュ 202枚で実績があるが、250m だと約800〜1,000枚になる。まず 500m に集約した約200枚で描き、タップした地点は 250m の値で示す。250m のまま描けるかは実機で確かめてから決める
3. 塗り分けは地震本部の5段階に合わせる。色相はハザードタイル(暖色)や人口(川藍)と区別できるものを選ぶ
4. 福智山断層帯は `F012101` の上端2点を `Polyline` で引き、凡例に「断層モデルの上端(深さ 3km)」と書く。名称、M7.2 程度、30年以内の発生確率ほぼ0〜3% は地震本部の長期評価から引く[^fukuchi]
5. 詳細シートには「今後30年に震度6弱以上: 9.5%」「地盤: 自然堤防(揺れが 1.84倍に増幅)」のように、確率と地盤を並べて出す。じぶん設定の自宅ピンがあれば、その地点の値を要約カードにも出す(教訓メモ §5.4 D1)
6. 出典は「J-SHIS 地震ハザードステーション(防災科学技術研究所)、2024年基準 NIED 作成版」とし、設定画面の出典一覧(NF-06)にも載せる

## 3. B2 治水地形分類図(地理院タイル)

### 3.1 使うデータと確認した事実

治水地形分類図(更新版)は、国が管理する109の一級水系の氾濫平野を対象に、土地の成り立ち(自然堤防、旧河道、後背湿地など)を分類した地図で、遠賀川も対象に入っている[^gsi-fc]。
地理院タイルとして配信され、ズームは 11〜16、出典表記が要る[^gsi-ichiran]。

```
https://cyberjapandata.gsi.go.jp/xyz/lcmfc2/{z}/{x}/{y}.png
```

直方市域(緯度 33.70〜33.81、経度 130.68〜130.81)をズーム14の 7×7 枚で確かめたところ、北東の 9枚(福智山側の山地)だけが 404 で、残りは中身のあるタイルが返った(2026-09-12)。
山地は治水地形分類図の対象外なので、この空白は仕様どおりである。
凡例には「山地は範囲外」と書いて、空白が安全を意味しないことを示す。

同じ地理院タイルの土地条件図(`lcm25k_2012`)は直方で 404 だった。
こちらは基本測量成果にあたり測量法の承認が絡むので[^gsi-ichiran]、使えたとしても避ける。

### 3.2 凡例と各地形のリスク

公式の凡例[^gsi-legend]から、直方の地図で意味を持つ分類を抜き出す。
リスクの説明は国土地理院の解説[^gsi-fc-content]による。

| 分類             | 凡例の色       | 解説が示すリスク                                                     |
| ---------------- | -------------- | -------------------------------------------------------------------- |
| 山地             | 薄い橙         | 洪水の影響は少ないが、豪雨時に土砂災害                               |
| 段丘面           | 橙             | 大規模洪水時に浸水しうるが、深さと時間は小さい                       |
| 氾濫平野         | 淡い緑         | 内水氾濫、地盤沈下と液状化                                           |
| 後背湿地         | 緑             | わずかな降雨でも浸水しやすく、浸水深と時間が大きい。地震の揺れに注意 |
| 微高地(自然堤防) | 黄             | 比較的安全だが、大規模洪水時には冠水                                 |
| 旧河道           | 青の横縞       | わずかな降雨でも浸水しやすく、液状化                                 |
| 盛土地・埋立地   | 黄地に赤の横縞 | 液状化と流動化                                                       |
| 現河道・水面     | 水色           | (河川そのもの)                                                       |

この凡例は、千葉豪雨の教訓「色が付いていない場所で浸水した」への答えになる。
洪水浸水想定(河川の氾濫)は「川があふれたらどこまで来るか」を示し、治水地形分類図は「川と関係なく水が溜まりやすい土地はどこか」を示す。
両方を重ねると、浸水想定の色が薄い場所でも後背湿地や旧河道なら注意が要る、と読める。
さらに B1 と組み合わせると、旧河道や後背湿地は液状化と揺れの増幅でも要注意という、水害と地震に共通する土地の弱さが一枚の地図で見える。

### 3.3 明治期の低湿地を見送る理由

明治期の低湿地(`swale`)は、明治期の地図から水田や湿地など液状化と関係の深い区域を抜き出したもので、位置に大きな誤差を含むことがあると国土地理院自身が注意している[^gsi-meiji]。
整備範囲は三大都市圏と全国の主要都市周辺 38地区で、直方市域は北半分だけタイルがあり(北九州地区の南端)、市の南半分と隣の飯塚市は 404 だった(2026-09-12 確認)。
市域の半分で空白になる図を重ねると、空白を「湿地ではなかった」と読まれる。
治水地形分類図の後背湿地と旧河道が同じ情報を市域全体で持つので、こちらで足りる。

### 3.4 利用規約

国土地理院コンテンツ利用規約[^gsi-terms]は公共データ利用規約(PDL1.0)に準じ、出典を「出典: 国土地理院ウェブサイト(URL)」の形で書けば利用できる。
加工した場合はその旨を書き、国土地理院が作ったものと誤解させてはならない。
治水地形分類図は地理院タイル一覧で「出典表記が必要」とされ、土地条件図のような基本測量成果の注記はない[^gsi-ichiran]。
既存のハザードタイル(ハザードマップポータルサイト)と同じく、タイルをそのまま重ねて出典を出す使い方に収まる。

### 3.5 実装の形

既存の `HAZARD_LAYERS`(洪水、土石流、急傾斜地、家屋倒壊)に1件足す形で済む。
変えるのは次の3点である。

1. レイヤーごとの出典。いまは洪水ポータルの出典を1つの定数で持っているので、レイヤーの型に出典を持たせて「国土地理院」を出せるようにする
2. 透過度。治水地形分類図は面をベタ塗りするので、既存の 0.7 では地名が読めなくなる可能性がある。実機で見て 0.5 前後に下げる
3. 凡例。公式凡例は約40項目あるので、§3.2 の8分類に絞る。色は既存レイヤーと同じく直方の実タイルから抽出して照合する

やさしい日本語モード(F-13)では、分類名の読みを添えるにとどめる(「後背湿地(こうはいしっち)」)。
正式名称は凡例の見出しに残す。

## 4. 要件への反映案

`requirements.md` を v1.6 とし、§3.1 に次を足す案。
受入条件は F-14 に倣う。

- **F-15 地震ハザードレイヤー**: J-SHIS の 250m メッシュ(30年以内に震度6弱以上の確率、微地形区分、増幅率)を市域ぶん静的にバンドルし、5段階で塗り分ける。福智山断層帯の位置を線で示す。タップで確率と地盤を表示する。機内モードで動く。受入条件: レイヤーを点けると塗り分けと凡例が出て、タップで「今後30年に震度6弱以上 ◯%、地盤 ◯◯」が出る。凡例に「安全度ではなく危険度」の注意書きがある
- **F-16 地形分類レイヤー**: 治水地形分類図を地理院タイルで重ねる。凡例は8分類に絞り、山地側が範囲外であることを示す。出典に国土地理院を表示する。受入条件: 洪水浸水想定と同時に重ねても浸水深の色が判読できる。設定画面の出典に国土地理院が載る

最終審査(10/10)までの扱いは、教訓メモ §6 の方針に従う。
プレゼンでは §2.2 の表(市内で 16倍の差、増幅率で説明)を数字として使える。
デモに載せるかは、静的 JSON の生成と実機での描画確認を終えてから判断日を置いて決める。
