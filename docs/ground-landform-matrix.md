# 地形分類と地盤分類の対応

アプリは土地の成り立ちを 2 つのレイヤーで見せている。
地形分類(治水地形分類図)は水の観点、地震ハザードの地盤(微地形区分)は揺れの観点で、どちらも同じ土地を分類している。
出典が違うため名称が食い違い、同じ土地に 2 つの名前が出る。
このドキュメントは両者の対応と、利用者が誤読しうる点をまとめる。

文言を直すときは、`src/constants/hazard-map.ts` の `LANDFORM_LEGEND` と `src/constants/quake-map.ts` の `JNAME_NOTE` の両方を見る。
データの仕様そのものは `docs/api-spec.md` の 6 章(J-SHIS)と 7 章(治水地形分類図)が正。

## 2 つのレイヤーの関係

どちらも出発点は同じで、分岐するのは土質から先である。

```
土地の成り立ち  →  土質  ┬→  水のたまりやすさ   … 地形分類(治水地形分類図)
 (どう積もったか)        └→  揺れやすさ・液状化 … 地盤(微地形区分)
```

観点が違うので、両者は同じ土地に別々の評価を与える。
一方が安全、他方が危険という組み合わせが実際に存在する。

| 項目     | 地形分類                                       | 地盤                                                |
| -------- | ---------------------------------------------- | --------------------------------------------------- |
| 出典     | 国土地理院 治水地形分類図(更新版)              | J-SHIS(若松・松岡 地形・地盤分類250mメッシュマップ) |
| 単位     | 図(タイル画像)                                 | 250m メッシュ                                       |
| 範囲     | 一級水系の氾濫平野とその周辺。山側は配信が無い | 市域全体(1,025 枚)                                  |
| 示すもの | 浸水のしやすさ、水の引きにくさ                 | 揺れの増幅、液状化のしやすさ                        |

## 利用者が誤読しうる 4 点

### 同じ土地に 2 つの名前が出る

レイヤーを切り替えると、同じ場所の名前が変わる。

| 地形分類         | 地盤           |
| ---------------- | -------------- |
| 段丘面           | 砂礫質台地     |
| 微高地(自然堤防) | 自然堤防       |
| 旧河道           | 旧河道・旧池沼 |
| 現河道・水面     | 河原           |

名称は出典の原文のまま出す方針(`JNAME_READING` の注記)なので、名称そのものは変えられない。
併記か相互参照で解く。

### 片方にしか出ない区分がある

市域の 53.1% にあたる丘陵と谷底低地は、地盤にしか名前を持たない。
治水地形分類図の配信範囲が一級水系の氾濫平野とその周辺に限られ、福智山側のタイルが無いためである。

逆に氾濫平野、盛土地・埋立地、切土地は地形分類にしか出ない。
250m メッシュは代表値を 1 つ取るので、人が造った土地は下にある自然地形の名前で分類される。

凡例の注意書き「白く抜けた所と山側は図の範囲外です。安全という意味ではありません」はこの非対称を指している。

### 評価が逆転する区分がある

自然堤防と盛土地は、水では安全側、地震では危険側に入る。

- **自然堤防**は川が運んだ砂でできていて、少し高いので水には強い。ゆるい砂と地下水は液状化の条件そのものなので、液状化は最も強い段階に入る
- **盛土地・埋立地**はかさ上げされているので冠水しにくい。人工の盛土は締まりが不足しやすく、液状化と沈下のおそれがある

後背湿地は逆の形で軸がずれる。
軟らかい粘土と泥炭なので揺れの増幅は市域で最大だが、粘土は液状化しないため、液状化では自然堤防より一段軽い。

揺れの大きさと液状化は別の軸であり、まとめて「地盤が悪い」と書くと、どちらの危険を指すのか読めなくなる。

### 縮尺が違う

地形分類は図をそのまま重ねるので、道路 1 本ぶんの幅の微高地も描かれる。
地盤は 250m メッシュの代表値なので、メッシュ内で最も面積の大きい区分に塗りつぶされる。
自宅が自然堤防の上にあっても、メッシュ全体が後背湿地なら地盤は後背湿地と出る。

同じ地点で 2 つのレイヤーが食い違って見えるとき、多くはこの縮尺差による。

## 文言で解くときの指針

- 地形分類の凡例で「比較的安全」と書く区分(微高地、盛土地)には、地震の一言を必ず添える。水だけを見た評価だと読ませない
- 「安全な順」という並べ方や見出しを使わない。軸が浸水、揺れの増幅、液状化の 3 本あり、順位が一致しない
- 地盤の説明では、揺れの増幅と液状化を分けて書く(`JNAME_NOTE` は既にこの形になっている)
- 山側で地形分類が白く抜ける件は、凡例の注意書きだけが根拠になっている。地盤レイヤーには谷底低地として出るため、片方が空なら他方を見る導線があるとよい
