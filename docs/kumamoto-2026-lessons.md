## 1. なぜ熊本地震を直方ベースの材料にするか

直方市は今回の地震で震度4を観測した[^yahoo-shindo]。
市域には福智山断層帯(M7.2 程度、30年以内の発生確率ほぼ0〜3%)が通っており、上限の3%は地震本部が最も警戒すべき S ランクの基準とする値である[^fukuchi]。
直方市の防災ブックには地震の章があるが、市が Web で公開しているハザードマップは浸水と土砂災害で、揺れやすさや液状化の地図は見つからなかった[^nogata-book]。

本アプリは水害を主軸に設計したが、熊本で起きた問題の多くは災害の種類に依らない。
避難所が開いているか、水はどこでもらえるか、車中泊の人に情報が届くか、偽情報をどう避けるか。
これらは遠賀川の氾濫時にもそのまま起きる。

## 2. 地震の規模と被害

- 発生: 2026-07-28 16:27。Mj7.1、深さ16km。宇城市と氷川町で震度7[^jma]
- 津波注意報(有明・八代海)を発表し、18:10 に解除。津波は観測されなかった[^wiki]
- 人的被害: 死者38人(8/31 時点)。うち直接死35人。初の関連死疑いは車中泊中の70代女性で、ガス欠でエアコンが止まり熱中症とみられる(7/30 氷川町)[^wiki][^kab-death]
- 住家被害: 全壊1,796棟、半壊3,457棟、一部破損30,993棟(8/31)[^wiki]
- 避難者: ピークは 7/30 の 415か所 10,467人。8/27 に 2,460人[^kumanichi-2000]
- ライフライン: 断水は17市町村 約14万戸(八代市はほぼ全域の約6万戸)。停電は最大 約4.9万戸[^ide][^nippon]
- 気象: 発災後に35℃超の猛暑日が続いた[^nikkei-heat]

## 3. 何の情報が足りなかったか

熊本で足りなかった情報は、時期と立場で性質が違う。
一括りに「情報不足」とせず、七つに分けて記す。

### 3.1 発災直後: 開いている避難所はどこか

震度7と6強を観測した8市町では、指定避難所のうち少なくとも23か所が開設できなかった。
理由は停電で冷房が使えないか、そもそも冷房が未設置だったことである[^nhk-23]。
宇城市では指定避難所の豊野防災拠点センターが使えず、駐車場を車中泊向けに開放した[^nhk-uki]。
体育館の冷房設置率は熊本県で約2割、全国でも33.1%にとどまる[^nikkei-heat]。

住民が最初に見る公式チャネルも止まった。
震度7の宇城市と氷川町は公式 LINE の障害で第一報を配信できず、熊本県の LINE にも緊急配信はなかった[^furusato1]。
一方で天草市は震度と概要を簡潔にまとめた配信をし、比較記事の筆者から最も見やすいと評価された。
同記事は「情報があること」より「住民がすぐ気付けること」が要るとまとめている。

熊本市の防災情報ポータルは、避難所ごとに開設状況、収容者数、混雑(満員/混雑/空きの3段階)、設備情報を一覧で出した[^kumamoto-portal]。
直方市の ArcGIS も `s_opening` で閉鎖と開設(混雑3段階)を持つので、同じ構造を既に持っている。
足りないのは設備(冷房、非常用電源、障害者トイレ、ペット)と「地震で使えるか」の区別で、市の避難場所一覧は対応災害種別(水害、地震、その他)を可否で示している[^nogata-list]。

### 3.2 数日から数週間: 給水、トイレ、通れる道、支援制度

断水14万戸に対し、給水所の情報は市町村ごとに別のサイトに散った。
地震翌日に県内の IT 企業が「くまもと被災者支援ナビ」を開設し、21市町村の公式発表を出典付きで集約して初めて、地図で給水所を探せるようになった[^shien][^jiji-yasashii]。
同サイトには「フタ付きの容器を持つ」「暑い時間帯を避ける」「1人で運べる量は10L(10kg)が目安」という実用知識が併記されている[^shien-mizu]。
個人が作った支援情報サイトも「給水はどこか、道路は通れるか、をすぐ知りたい。長文記事ではなく最新情報への入口が要る」と動機を書いている[^kurumi]。
市の給水車配備(熊本市15か所)があっても、高齢者や乳幼児のいる世帯が何度も運べるとは限らない、という指摘もある[^ide]。

トイレは避難所206か所 約8千人に対し、簡易トイレ1基あたり数十人から100人超で、20分待ちが生じた[^toilet]。
排水管の破損で「水が出ても非常用トイレを」と市が呼びかけたが、簡易トイレの自宅備蓄率は約2割である[^toilet]。
不衛生なトイレを避けて水分を控え、脱水や熱中症に至る連鎖も懸念された[^jiji-toilet]。
発災48時間でトイレ、温かい食事、ベッドを整える「TKB48」は、10年前と同じく実現しなかった[^kab-tkb]。

道路は、高速道路と主要道の通行止めで国道3号に車が集中し、支援輸送に支障が出た[^jahic]。
国土交通省は「通れるマップ」を GeoJSON で公開した[^mlit-road]。

支援制度は罹災証明が入口で、被害区分(全壊、大規模半壊、中規模半壊、半壊、準半壊)ごとに支援金や減免が変わる。
17市町村でマイナポータルからのオンライン申請ができた[^impress]。
住民が必要とする情報は、避難情報から道路、窓口、ごみ収集へと時間とともに移る[^furusato2]。

### 3.3 見えない避難者: 車中泊と在宅避難

時事通信の全国調査で、45道府県(96%)が避難者の所在把握を課題と答えた[^jiji-survey]。
熊本市は車中泊用の専用駐車場を2か所用意したが、利用は最大でも約70台で容量の3分の1以下だった。
自宅近くで車中泊した人が多かった、と市は説明している[^risk-car]。
10年前の県調査でも、最も長く避難した場所は「自動車の中」が47.2%で最多、理由は「余震が続き、車が一番安全と思った」が79.1%である[^risk-car]。

在宅避難の高齢者には物資が届かなかった。
八代市鏡町の84歳の女性は、市に物資が届いていると聞きながら自宅には配られず、粥でしのいだ。
運転免許を返納した77歳の女性は、1km 先の避難所まで歩けなかった[^kumanichi-invisible]。
「避難所に行けば物資はもらえる」構造のため、行けない人はボランティア頼みになった[^chosyu]。
ホテルへの2次避難は申込1,166件に対し成立253件で、遠方に移ると片付けや通院ができないことが理由だった[^kumanichi-2nd]。

ペットの同行避難は八代市が全避難所で受け入れたが、専用室が満員で使えない例があった[^pet]。
福祉避難所は、2016年に益城町で5か所を指定しながらほぼ開設できなかった。
住民側の備えとして、福祉避難所の一覧と受け入れ条件、避難行動要支援者名簿への登録状況を確認し、そのページを家族の LINE に共有しておくことが勧められている[^koka-welfare]。

### 3.4 偽情報が救助と判断を妨げた

実在しない住所からの偽の救助要請が30万回以上閲覧され、消防と警察の資源を消耗させた[^piyolog]。
イオンモール熊本の爆発を装った生成 AI 動画、能登半島地震の映像の転用、人工地震説(340万回閲覧)、「外国人が放火した」というヘイト投稿(1,100万回超)、PayPay による送金詐欺が確認された[^piyolog][^koka-dema]。
ヘイト投稿は被災地で車を撮影されるといった実害を生んだ[^piyolog]。
X の「おすすめ」欄が機能せず、「フォロー中」「新しい順」への切り替えが呼びかけられた[^note-smapho]。

専門家の提案は二つある。
「災害時にはデマが流れる」という認知を平時から広げること、そして共有前に発信元を確認し、確信がなければ拡散しないことである[^tokyo-np][^koka-dema]。
推奨される一次情報は気象庁、首相官邸、県の公式サイトである[^koka-dema]。

### 3.5 スマホそのものが使えない時間帯

音声通話は規制がかかり、基地局の停電で一部地域は通信障害になった[^jiji-benri]。
猛暑で端末が熱停止し、停電で充電できなかった[^note-smapho]。
災害用 Wi-Fi「00000JAPAN」は県全域で開放されたが暗号化がなく、カード情報の入力は避けるよう注意が出た[^itmedia-wifi]。
ある開発者の総括は「スマホは電気、通信、正確な情報(今回は気温も)がそろって初めて強い道具」で、備えとして家族の連絡先や集合場所を紙に書くこと、オフライン地図と避難所情報のスクリーンショット、171 の練習を挙げている[^note-smapho]。

### 3.6 外国人住民にはやさしい日本語が求められた

熊本市国際交流会館が多言語支援センターと外国人向け避難所を開設し、やさしい日本語、英語、中国語、韓国語で発信した[^kumanichi-foreign]。
県は在留外国人の半数超がベトナムやインドネシア出身で英語が母語でないことから、英語よりやさしい日本語を優先した[^jiji-yasashii]。
東京都の調査でも、やさしい日本語を読みたい外国人は41.3%で英語の35.9%を上回る[^jiji-yasashii]。
実例として「水をくばる場所があります。お金はいりません」という文が挙がっている[^jiji-yasashii]。
本アプリの F-13 の方針(翻訳ではなくやさしい日本語)は、この教訓と一致する。

### 3.7 千葉豪雨: 色が付いていない場所で浸水した

同じ夏の千葉豪雨では、被害報告約2万件の分析で、55.7% が低位地帯または浸水想定区域の外で被災した[^wn-chiba]。
原因は1時間100mm超の雨が下水道の処理能力(50mm 前後)を超えた内水氾濫で、駅周辺やアンダーパスで顕著だった。
千葉市では約2,500台が路上に放置され、水没した車内で3人が亡くなった[^tokio-chiba]。
洪水ハザードマップは河川の氾濫を想定するため、川のないくぼ地の浸水は反映されにくい。
分析記事は「色が付いていない場所だから安全とは限らない」とし、標高と過去の浸水履歴の把握を勧めている[^wn-chiba]。

## 4. 防災意識はどこで止まっているか

防災の必要性を感じる人は76%いる[^cross-ishiki]。
しかし家庭の備えが「できている」人は26%で、避難場所の所在が「わからない」人が63%、避難場所までの移動時間を把握している人は34%にとどまる[^cross-sonae]。
警戒レベルにかかわらず避難しないと答えた人は24%で、20〜30代では3割を超える[^cross-ishiki]。
避難場所と避難所の違いを説明できる人は20%、地域の避難訓練に直近1年で参加した人は11%である[^cross-ishiki][^cross-sonae]。
不安な災害は地震68%、台風48%、豪雨28%の順で、豪雨への不安は地震の半分以下である[^cross-ishiki]。

意識(76%)と行動(26%)の差を埋めるものについて、調査と研究が示す方向は三つに絞れる。

- **場所に固定された具体**: 環境省のナッジ事業では、指定避難場所を自分でマグネットに書いて日常の目につく場所に貼ることで認知が上がったと報告されている[^nudge]。「自宅から避難所まで何分か」「うちの避難所に冷房はあるか」のような、一般論ではなく自分の場所の答えが行動につながる
- **体感**: 長野県は AR の浸水動画で災害を「自分事」にし、逃げ遅れゼロを目標に掲げる[^nagano-ar]。国土交通省中部地方整備局は、目の前の場所が浸水現場になる AR を「気づかなかった危機認知」の誘因と位置づける[^cbr-ar]。本アプリの AR は、この路線にある
- **平時から使われること**: 防災アプリはスマホ所有者の約半数が入れているが、平時の利用頻度が高い人ほど災害時にも使う(災害時利用は約7割)[^moba-ken]。平時に開く理由がないアプリは、災害時にも開かれない

知識が届いていない例もある。
ペットボトル水は賞味期限を過ぎても未開封なら飲めることが多い(期限は容量を保証する期限)が、2016年には期限切れの支援水130トンが3年後まで山積みになり、2026年にもこの知識の投稿に5千件超の反応が付いた[^ide]。

## 5. 直方ベースへの示唆

前提として、本アプリの制約(サーバなし、ArcGIS は読み取り専用、じぶん設定は端末内のみ、デモモードはオフライン)は変えない。
その範囲でできることと、範囲外として市に提案すべきことを分けて並べる。
採否は `requirements.md` の判断日ルールで決める。

### 5.2 新しいレイヤーの候補

**B1 地震ハザード(J-SHIS)**。
防災科研の地震ハザード情報提供 API は、250m メッシュごとに30年以内の震度6弱以上の確率、超過確率3%の計測震度、表層地盤の増幅率を GeoJSON で返す。
経度緯度指定で WGS84 が使え、認証は要らない[^jshis-api]。
直方市には地震のハザードマップがない(§1)ので、市民が自分の地盤の揺れやすさを見る手段を本アプリが提供できる。
人口レイヤー(F-14)と同じく市域を切り出して静的バンドルにすれば、機内モードでも動き NF-04 と整合する。
規約、実データ、実装の形は `docs/quake-ground-layers.md` §2 にまとめた。
市内7地点の30年以内に震度6弱以上となる確率は 0.6% から 9.5% で、表層地盤の違いで16倍の開きがある。

**B2 低地と旧河道(地理院タイル)**。
治水地形分類図(`lcmfc2`)と明治期の低湿地(`swale`)は地理院タイルとして配信されており、既存のハザードタイルと同じ UrlTile で重ねられる[^gsi-tiles]。
千葉の教訓(§3.7)の「色が付いていない場所」に対する、キー不要の補助線になる。
直方市域で確かめた結果、治水地形分類図は山地側を除いて整備済み、明治期の低湿地は市の南半分が未整備だった(`docs/quake-ground-layers.md` §3)。
空白を安全と読まれる恐れがあるため、明治期の低湿地は見送り、治水地形分類図だけを採る。

**B3 応急給水拠点**。
熊本では給水所を探せるようになるまで民間の集約を待った(§3.2)。
断水前に「どこで水をもらうか」を知っておく価値があるが、直方市の応急給水拠点は Web で見つからず、市への確認が要る。

通れる道は、国土交通省の「通れるマップ」が災害ごとの公開で平常時のデータがない。
直方では既存の交通規制レイヤー(市の ArcGIS)がこの役割を担うので、追加は要らない。

### 5.3 サーバなしではできないこと

車中泊と在宅避難の自己申告、ユーザー投稿による災害マップ、プッシュ通知は、いずれも常時稼働のサーバと投稿の確認体制が要る。
自己申告は位置情報を外部に送ることになり、NF-07 と衝突する。
これらは本アプリの機能ではなく、市のシステム側の課題として提案書に書く。
代わりにアプリでできるのは、発災後のフェーズ(直後、数日、数週間)ごとに「いま見るべき公式情報」をリンクで並べる入口画面である(A5 の拡張)。

### 5.4 平時に開いてもらう仕掛け

**D1 わが家の防災カルテ**。
自宅ピン一つから、想定浸水深、地震の30年確率(B1)、水害時と地震時の最寄り避難所と徒歩分数(A3)、給水拠点(B3)を1画面にまとめる。
端末内だけで完結し(NF-07)、スクリーンショットで家族に共有したり紙に印刷したりできる。
ナッジ研究のマグネット(§4)をアプリに置き換えたものになる。

**D2 AR の初期値を自宅の想定浸水深にする**。
既に F-08 のストレッチゴールにある。
千葉の教訓は「川から離れていても」であり、AR は場所を選ばずに使える点を前面に出せる。

**D3 根拠付きの短い知識をホームに出す**。
「ペットボトル水は期限切れでも未開封なら飲めることが多い」「簡易トイレは1家庭35回分」「給水は10L(10kg)まで」のように、数字と出典を添えた一枚カードを日替わりで出す。
平時に開く理由を作る(§4 の三つ目)。

**D4 家族の決めごとチェックリスト**。
連絡方法、集合場所、171 の練習、を端末内に保存する。
熊本の総括(§3.5)が「いちばん軽視されている備え」と呼んだ項目である。

## 6. 進め方の提案

最終審査(10/10、資料締切 9/30)までに実装を増やすより、熊本の教訓を受け止めた形をプレゼンで示すほうが配点(プレゼン50点)に効く。
候補の中で審査までに収まる大きさなのは A1、A3、A5 である。
B1 は審査員に伝わりやすいが、J-SHIS の規約とデータ取得の検証を先に済ませる必要がある。

残りはコンテスト後の要件として、`requirements.md` に v1.6 の節を設けて並べる。
実装前に直方市へ確認すべきことは、避難所の冷房と非常用電源の有無、応急給水拠点の場所、内水の浸水実績図の有無、地震ハザードマップの公開予定、の四つである。

2026-09-12 に次の3点を決めた。

1. 最終審査のプレゼンで熊本地震の教訓を前面に出す
2. 地震を本アプリの守備範囲に入れる(アプリ名は防災を冠していないので拡張の余地がある)
3. 今回はサーバなし原則を維持し、§5.3 は市への提案にとどめる。将来の実運用ではサーバが必須になる

B1 と B2 の調査結果は `docs/quake-ground-layers.md` にある。
直方市の災害史の所在と読み取りは `docs/nogata-disaster-history.md` にある。
確認した資料の一覧と利用可否は `docs/source-register.md` にある。
