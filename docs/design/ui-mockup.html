直方ベース

遠賀川のまちの、ふだんの入口。

防災アプリの「非常時の赤」で塗らない。ふだん開きたくなる生活アプリの顔で作り、危険は水の言葉(平常・注意・危険)で静かに、しかしはっきり語る。本版は実装済みの機能構成(F-01〜F-13)を反映したカンプで、画面の要素・文言は実アプリと対応する。

デザインの前提

川藍を基調に

アイデンティティの中心は遠賀川。主色は川藍(#1E4E79)、背景は生成りの紙色。緊急色は状態表示のためだけに取っておく。

状態は3色の水の言葉

平常(緑)・注意(橙)・危険(赤)を全画面で共通化。ピンもバーもチップも同じ言語を話す。灰色は「閉鎖・データなし」。

平常時が主役

平常時は空データが正常系(要件 NF-05)。「何もない」を安心の表示として設計し、災害時の姿はデモモード(紫)で切り替えて見せる。

だれでも読める

文字サイズは標準・大きめ・特大の3段階。やさしい日本語モード(F-13)では全文言がふりがな付きの平易な表現に切り替わる。

S-01 ホーム地図(平常時とデモモード)

同じ画面がトグルひとつで災害時の姿になる。これがデモブースの主役(要件 F-09)。要約カード「いまの状況」はたためる。デモモード中は紫のバナーを常時表示し、有効化と同時に地図が直方市中心(直方駅付近)へ戻る。圏外のときは墨色の「オフライン — 情報を更新できません」の帯を同じ位置に出す(NF-04)。

v1.6 以降の変更(この絵には未反映。凍結後に実機のスクリーンショットで置き換える): レイヤーの切替はチップの並びをやめ、地図上の1つの「レイヤー」ボタンから開くシート(S-09)に集めた。シートは「いまの状況(ピン: 避難所・車中泊避難所・水位・被害報告・交通規制)」「塗り(1つ選ぶ: なし・洪水の浸水想定・地震ハザード・地形の分類)」「重ねる区域(土砂災害警戒区域・家屋倒壊等氾濫想定区域・人口)」「記憶(自然災害伝承碑)」の4区分。地図の上には表示中の塗りと区域の凡例を1行の帯にまとめ、ⓘ で全文と出典を読める。要約カードの AR 導線は「現在地の想定浸水深を AR で見る ›」で、自宅ピンがあれば水害時と地震時の最寄り避難所が「道のり 約◯m・徒歩 ◯分以上」つきで出る。

S-02 / S-03 水位と避難所の一覧

水位一覧は「本物のデータが動いている」ことの実証点(要件 F-03。観測時刻を各行に出す)。避難所一覧は対応災害でしぼれて、自宅ピンを置くと道のり順に並び、行に「道のり 約◯m・徒歩 ◯分以上」が出る(v1.6。直線距離では対岸の避難所が最寄りになるため道のりにし、分数は下限として示す)。どちらも圏外ではキャッシュを表示し「◯月◯日 ◯:◯ 時点の情報」と古さを明示する(NF-04)。

S-04 AR 浸水体験

本作品の核(要件 F-08)。起動すると現在地の想定浸水深をハザードタイルから読み、水面の初期値にする。水面は実写の濁流ループ動画をテクスチャにして床アンカーへ敷き、人物セグメンテーションで「人が水に浸かる」見え方を作る。

S-05 / S-06 / S-07 詳細シート、設定、じぶん設定

詳細シートは地図の文脈を保ったまま画面下に重ね、要約カードと入れ替わる。同型のシートが地震メッシュ(確率3値、地盤、増幅率)、人口メッシュ(地域名、目安の人数、65歳以上)、伝承碑(碑名、災害名、建立年、伝承内容)にもある。その他画面は「備え / アプリ / 出典・免責」の3群。じぶん設定は住所を入力させず、地図をタップするか現在地ボタンでピンを置くだけにする(要件 F-12 / NF-07)。

S-xx / F-xx は要件定義書(Obsidian「直方ベース 要件定義書」)の画面・機能 ID に対応。地図は抽象表現、画面内の数値・住所はダミー(観測点名・避難所名は実データより)。デモモードの件数はデモシナリオのフィクスチャに準拠。

ハザード凡例色はハザードマップポータルサイト(国土交通省)の配信タイルに準拠。実装は react-native-maps + UrlTile で洪水・土石流・急傾斜地・家屋倒壊(氾濫流、河岸侵食)の5タイルと、地理院タイルの治水地形分類図を重ねる。地震ハザードと人口は同梱した静的データを面で描く(データソース仕様書 §6、§11、§12)。

本カンプの絵は v1.5 時点(2026-08)のもので、v1.6 以降の変更(S-01 のレイヤー選択シートと凡例の帯、S-03 の道のり表示、S-06 のシナリオ行、S-08〜S-10)は本文の注記と要件定義書を正とする。凍結(2026-09-27)後に実機のスクリーンショットで差し替える。

すべての文言は標準とやさしい日本語(F-13。ふりがな付き・分かち書き)の2系統を持つ。本カンプは標準表記のみ示す。
